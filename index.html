Integration & API Reference 100% client-side TypeScript bundle · Zero runtime dependencies

1. Script Inclusion

Include the standalone browser bundle. It exposes the global window.snapuml namespace.

<script src="snapuml.min.js"></script>

Also available as ES Module via dist/snapuml.esm.min.mjs.

2. Programmatic Rendering

Call snapuml.render(code) to compile diagram text into an inline SVG string. Diagram type is detected automatically.

const code = 'Alice -> Bob: Hello';
const svg = snapuml.render(code);

document.getElementById('output').innerHTML = svg;

Explicit compilers: renderSequenceDiagram, renderComponentDiagram, renderSaltDiagram, renderWireDiagram.

3. DOM Auto-Initialization

Use snapuml.initialize() to replace all matching <pre class="snapuml"> elements on page load.

snapuml.initialize({
  startOnLoad: true,
  selector: 'pre.snapuml'
});

Non-throwing: syntax errors render an inline diagnostic SVG block.
